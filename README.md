## Что это

PULSE — это официальный клиент Яндекс Музыки с пересобранной оболочкой. Плеер внутри тот же,
всё остальное своё: тёмная фиолетово-циановая тема, собственное меню, своя нумерация версий.
В заголовке окна написано **PULSE**, а не «Яндекс Музыка 5.118.1».

## Установка

1. Скачайте **`PULSE-V3-Setup-3.1.0.exe`** из [последнего релиза](https://github.com/Slesari690/PULSE/releases/latest).
2. Если стоит предыдущая версия PULSE — полностью закройте её (трей → выход) и запустите установщик поверх.
3. Установите и запустите ярлык **PULSE**.

Официальную Яндекс Музыку удалять не нужно, приложения не конфликтуют.

## Как пользоваться

Кнопка **«Меню PULSE»** находится в левой панели над вашим профилем. Если по какой-то причине
её там нет, появится плавающая кнопка в левом нижнем углу — она делает то же самое.

**Скачать трек:** включите песню, дайте ей проиграть пару секунд → «Меню PULSE» → «Скачать текущий трек».
**Скачать альбом или плейлист:** откройте его страницу → «Меню PULSE» → «Скачать весь альбом».

Файлы попадают в папку загрузок мода, её можно сменить в том же меню.

**Сменить тему:** «Меню PULSE» → раздел «Тема плеера». Тема применяется сразу и запоминается.
По умолчанию стоит «PULSE» — та же тёмная фиолетово-циановая, что и раньше.

В шапке меню есть строка диагностики: состояние аккаунта, модулей и ключа подписи.
Если что-то не работает, там будет видно, что именно.

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Media Play / Pause` | Пауза и воспроизведение |
| `Media Next / Prev` | Следующий и предыдущий трек |
| `Ctrl + Shift + L` | Лайк текущего трека |
| `Ctrl + Shift + D` | Скачать текущий трек |

## Известные ограничения

- Яндекс может показать уведомление «уязвимость в приложении» — мод его обходит, на работу не влияет.
- Если «Моя волна» отключена на стороне аккаунта, мод это не лечит: это блокировка самого аккаунта.
- Несколько процессов `PULSE.exe` в диспетчере задач — это нормально. Так устроен Electron:
  отдельные процессы под основную логику, GPU, сеть и саму страницу. Официальный клиент работает так же.
- Только Windows x64.

## Сборка из исходников

```bash
bun install
bun start        # скачает клиент Яндекса, пропатчит и соберёт установщик
```

Готовый установщик появится в `.versions/<версия>/mod/dist-pulse/`.

Быстрая пересборка только интерфейса и иконки:

```bash
bun run ui:build
node scripts/make-icon.js
```
